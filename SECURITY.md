# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security of local data processing is a top priority for Datalysis. Because Datalysis runs entirely locally on your machine and communicates with zero external third-party cloud services or LLMs, your data never leaves your environment.

If you discover a security vulnerability or security bug (such as unsafe parsing or path traversal in file uploads):

1. **Do not create a public GitHub issue.**
2. Please report the issue via GitHub's Private Vulnerability Reporting feature on the repository.
3. Include detailed reproduction steps and affected files.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to release a patch promptly.
